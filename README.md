# REFLECT CLINIC — عيادات ريفلكت (Full-Stack Arabic Medical Website)

موقع عربي فاخر ومتكامل لعيادات **Reflect Clinic — عيادات ريفلكت** مبني بدعم كامل لاتجاه RTL، وهوية بصرية مركزية، وقاعدة بيانات PostgreSQL فعلية مع Drizzle ORM، ونظام طلب مواعيد متعدد الخطوات، وجدول ساعات عمل تفاعلي ذكي.

---

## 1. الهوية البصرية ونظام التصميم (`src/app/globals.css`)

- **الألوان الأساسية المعتمدة:**
  - العنابي (`--color-primary`): `#650D3D`
  - الوردي (`--color-accent`): `#F04491`
  - الفستقي (`--color-secondary`): `#C5D6A0`
  - الأوف وايت (`--color-background`): `#F8F4F0`
  - الأبيض (`--color-surface`): `#FFFFFF`
- **الخط العربي:** `Alexandria` بالأوزان `400`, `500`, `600`, `700`.

---

## 2. البيانات المركزية (`src/data/`)

- `src/data/siteConfig.ts`: الإعدادات المركزية للعيادة، المنطقة الزمنية (`Asia/Riyadh`)، جدول الدوام الأولي، بيانات التواصل، ومصادر الصور الفوتوغرافية المرخصة.
- `src/data/departments.ts`: الأقسام الثلاثة (`body`, `skin`, `face`) بأيقونات Lucide فقط دون صور داخل بطاقات الأقسام.
- `src/data/services.ts`: جميع الخدمات الـ **19** المعتمدة، مع تحديد **12 خدمة متنوعة** للظهور في الصفحة الرئيسية، وربط كل خدمة بالقسم والأطباء الذين يقدمونها.
- `src/data/doctors.ts`: جميع الأطباء الـ **24** (9 في قسم الجسم، 7 في قسم الجلد، و8 في قسم الوجه، مع الاحتفاظ باسم «العرفج» كما ورد).

---

## 3. الصفحات والمسارات

1. `/` — الصفحة الرئيسية (بالترتيب: Hero ← نبذة مختصرة ← 12 خدمة متنوعة ← زر جميع الخدمات ← الأقسام الثلاثة ← من نحن ← الأطباء ← كيف تحجز ← ساعات العمل ← التواصل وواتساب ← الموقع ← CTA للحجز ← Footer).
2. `/services` — جميع الخدمات الـ 19 مع البحث والتصفية وتحديد البطاقات.
3. `/services/[slug]` — صفحة تفاصيل الخدمة المستقلة وتعرض شرح الخدمة والأطباء المسجلين لتقديمها.
4. `/departments` و `/departments/[slug]` — صفحات الأقسام الثلاثة (`body`, `skin`, `face`).
5. `/about` — صفحة «من نحن — تعرّف على قصتنا ورؤيتنا في العناية».
6. `/doctors` و `/doctors/[slug]` — دليل الأطباء الـ 24 مع البحث العربي المُطبَّع والفلاتر وصفحة مستقلة لكل طبيب.
7. `/book` و `/booking` — نظام طلب حجز الموعد متعدد الخطوات (5 خطوات).
8. `/how-to-book` — كيف تحجز.
9. `/working-hours` — جدول ساعات العمل التفاعلي الذكي.
10. `/faq` — الأسئلة الشائعة (Accordion يدعم لوحة المفاتيح و `aria-expanded` و `aria-controls`).
11. `/contact` — تواصل معنا ونموذج المراسلة المتصل بقاعدة البيانات.
12. `/location` — موقع العيادة والعنوان والاتجاهات.
13. `/privacy` — سياسة الخصوصية.
14. `/admin` — لوحة الإدارة المحمية.

## 4. التشغيل والبناء والاختبار

```bash
# تثبيت الحزم
npm install

# توليد الأنواع وفحص TypeScript
npx next typegen
npm exec tsc -- --noEmit

# تشغيل الاختبارات الآلية للتحقق من البيانات والمنطق
npx tsx src/tests/verify-clinic.ts

# بناء نسخة الإنتاج
npm run build

# تشغيل الخادم
npm run dev
```
